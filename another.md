# Another venue

This is the same install as a first venue. The terminal lists the venues already on this Google account. The last line, "None of these", sets up another one.

The same billing account is fine, and the same Soniox account is fine. When it asks for a Soniox key, create a new one. That is the recommended choice.

## Start

Click the **copy** button on the box below (it pastes into the terminal at the bottom of the screen), then press **Enter**. Use the venue Google account.

```bash
./setup.sh
```

When the terminal says **Done!**, open the new link it prints and bookmark it on its own. You can open it in this same browser. The first venue's link still belongs to the first venue.
