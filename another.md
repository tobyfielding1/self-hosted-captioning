# Another venue

Use this to run a second session at the same time, on the same Google account. The one you already have stays as it is.

The same Google billing account is fine, and the same Soniox account is fine. When it asks for a Soniox key, create a new one. That is the recommended choice.

## Start

Click the **copy** button on the box below (it pastes into the terminal at the bottom of the screen), then press **Enter**. Use the church Google account.

```bash
./deploy.sh --new-project
```

When the terminal says **Done!**, open the new link it prints and bookmark it on its own. You can open it in this same browser. The first venue's link still belongs to the first venue.
