# Another church

Use this to add a second captions server on the same Google account, for another church or another room. The one you already have stays as it is.

## Start

Click the **copy** button on the box below (it pastes into the terminal at the bottom of the screen), then press **Enter**. Use the church Google account.

```bash
./deploy.sh --new-project
```

When the terminal says **Done!**, open the new link it prints and bookmark it on its own. You can open it in this same browser. The first church's link still belongs to the first church.
